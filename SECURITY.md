# Security policy

muru-hosting is a proof of concept. It is not run as a service, it has no
supported releases, and nothing should be hosted on it that needs
protecting. Its design is about isolating sites from each other and from
the control plane, so problems with that design are welcome.

## Reporting a problem

- **A problem in muru-hosting's design or code:** open an issue in this
  repository with the `security` label. Since no one depends on it, an
  open report is the quickest way to get it considered.

- **A problem in Muru itself,** even one found through muru-hosting:
  report it as Muru's [security policy](https://github.com/muruhq/muru/blob/main/SECURITY.md)
  describes, not here.

If you are unsure which it is, report it through Muru's policy.
